# nhl_data_display_platform_frontend

This Flutter app displays today’s games using real-time data from Firestore. It includes a games list screen with live score updates and a detail screen showing full game information. The app supports loading and error states, handles missing data safely, provides a basic live-game filter, and leverages Firestore caching for simple offline behavior.
